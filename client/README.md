# HubCommerce Pro - Frontend

Modern, glassmorphic management interface built with React and Vite.

## 🛠 Available Scripts

- `npm run dev`: Runs the app in development mode at `http://localhost:3000`.
- `npm run build`: Builds the app for production to the `dist` folder.
- `npm run preview`: Locally preview the production build.
- `npm run lint`: Lint the project using ESLint.

## ⚙️ Configuration

Copy `.env.example` to `.env` and configure your `VITE_API_URL`.

```env
VITE_API_URL=http://localhost:5000/api
```

## 🎨 UI & UX
- **Glassmorphism**: High-end visual style using custom CSS variables.
- **Micro-animations**: Powered by `framer-motion`.
- **Dynamic Charts**: Interactive business metrics with `@mui/x-charts`.
