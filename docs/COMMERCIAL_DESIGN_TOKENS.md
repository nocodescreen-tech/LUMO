# LUMO / 5DEV visual direction
Brand: #F97316 orange, #171717 ink, #FFFFFF white, #F7F7F5 warm porcelain. Primary action #C2410C on white text (distinct from brighter brand orange). Secondary semantic hues: green for success, blue for info, amber for warning, red for errors, violet only for analytical series. Dark: #141414 background, #202022 surface, #FAFAFA text, #FDBA74 accent. Tokens are in client/src/design-system/commercial.css. Landing and auth consume shared colors. This is a token migration, not the full redesign. All screens need a real visual/contrast pass, especially hardcoded charts, landing illustrations and logo assets. No new logos or photos generated. Senior design direction: editorial typography, human photography, restrained motion, clear hierarchy, practical dense data tables, no decorative robot illustrations.
